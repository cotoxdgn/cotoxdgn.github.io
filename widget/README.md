# ホーム画面のウィジェット（iPhone・Scriptable）

iPhone のホーム画面に、次のものを出します。20分ごとくらいに読み直します（iPhone の都合で少し遅れることがあります）。

- **タスク表**：今日の未完了の件数（持ち越し＋今日）、上から3つの名前（アプリと同じ順。👤待ち・前提待ちは名前に出さない）、持ち越しの件数
- **ルーティン**：今日の習慣の ○×、全部できた日の連続日数、生理の次の予定日（「あと○日」。始まっているときは「○日目」）

電波がないときなどは、最後に読めた内容を出し、下に小さく「更新できませんでした 時刻」と出ます。
ウィジェットを押しても特別なことはしません（Scriptable が開くだけ）。

## 使う合言葉について

ウィジェットには**見るだけ用の合言葉**を貼ります。いつもの合言葉は貼らないでください。
見るだけ用の合言葉で出来るのは、上の内容を見ることだけです（記録を書く・消す、睡眠・コレクション・メモ・ほかのアプリのデータを読む、などはできません）。
漏れたかもと思ったら作り直して、スクリプトに貼り替えてください（いつもの合言葉や、ほかの端末のつなぎ直しは不要です）。

## 準備（1回だけ）

### 1. スプシのプログラムを新しくする

- ルーティン（共通のスプシ）：`gas/Code.gs` を貼り替えて［デプロイ］→［デプロイを管理］→ 鉛筆 →「新バージョン」→［デプロイ］
- タスク表：タスク用の Apps Script（script.google.com で作った専用のプロジェクト）に `task/gas/TaskApi.gs` を貼り替えて、同じように「新バージョン」でデプロイ

どちらも URL は変わりません。新しい許可（権限の確認）も出ません。

### 2. 貼る値を4つ用意する

| 貼る場所（スクリプトの上の方） | どこで見るか |
|---|---|
| `routineUrl` | ルーティンのアプリ →「習慣」→ 設定の「ホーム画面のウィジェット」→「送り先URL」の［コピー］ |
| `routineKey` | 同じ画面の「見るだけ用の合言葉」の［コピー］（スプシの「設定」シートの B6 と同じ） |
| `taskUrl` | タスク用の Apps Script で関数 `taskApiShowViewKey` を実行 → 実行ログの「送り先URL」（［デプロイを管理］のウェブアプリURL、…/exec で終わるもの） |
| `taskKey` | 同じ実行ログの「見るだけ用の合言葉」 |

- タスク表の見るだけ用の合言葉を作り直すときは、関数 `taskApiRenewViewKey` を実行します
- ルーティンの見るだけ用の合言葉を作り直すときは、上の画面の「見るだけ用の合言葉を作り直す」を押します

### 3. Scriptable にスクリプトを入れる

1. App Store で「Scriptable」（無料）を入れて開く
2. 右上の「＋」（新しいスクリプト）を押す
3. `widget/kotowidget.js` の中身を全部コピーして貼る
4. いちばん上の `CONFIG` の `''` の中に、2. の4つを貼る（`'` は消さない）
5. 上の名前を押して「コトのウィジェット」などにする →「Done」
6. 一度そのまま ▶ で実行 → 中サイズの見本が出れば完成

### 4. ホーム画面に置く

1. ホーム画面の何もないところを長押し → 左上の「＋」（または「編集」→「ウィジェットを追加」）
2. 「Scriptable」を選ぶ → 「中」（横長）を選んで「ウィジェットを追加」
3. 置いたウィジェットを長押し →「ウィジェットを編集」→「Script」で 3. のスクリプトを選ぶ
4. 「When Interacting」はそのまま（Open App）でかまいません

小・大のサイズでも動きます（小は数字だけ、大は習慣を多めに出します）。

## 困ったとき

- 「未設定」と出る：`CONFIG` の URL か合言葉が空です
- 「合言葉が違います」：見るだけ用の合言葉を作り直したあとなら、新しい合言葉を貼り直してください
- 「Apps Script が古いようです」：1. の「新バージョンでデプロイ」がまだです
- 「つながりません」：電波を確かめてください。前に読めた内容があればそれを出します

## 試験（パソコンで）

```
TZ=Asia/Tokyo node widget/test/widget.test.js
```

Scriptable の部品（Request・ListWidget など）をまねして、読めたとき・読めなかったとき・未設定のときに表示が崩れないかを確かめます。

# ホーム画面のウィジェット（iPhone・Scriptable）

iPhone のホーム画面に、**大きいウィジェット1つ（4×4）**を置くだけで、天気・予定・タスク・ルーティン・歯みがき・脳みそが全部出ます（2026-11-05 から。中くらいのサイズで置いても、ルーティン・歯みがき・脳みそだけの表示で使えます）。
どちらも同じスクリプトで、置いたサイズで中身が変わります。15分ごとくらいに読み直します（iPhone の都合で少し遅れることがあります）。

**大（4×4）**

- **日付と天気**（大阪）：今の気温・最高と最低・降水確率・天気、3時間ごとの気温と降水確率を6つ。18時からは明日の予報
- **予定**（Googleカレンダー）：今日の予定を5件まで（今やっている予定は太字、終わった予定は出さない）と、明日の最初の1件。今日の予定が全部終わったら（予定の無い日は18時から）明日の予定
- **タスク**：今日の未完了の件数、上から5つ（アプリと同じ順。持ち越しには「持越」の印。👤待ち・前提待ちは名前に出さない）、「待ち○件・明日○件」。18時からは今日の残りと明日のタスク

**中（4×2）**

- **ルーティン**：今日の習慣の ○×、全部できた日の連続日数、生理（「○日後」。始まっているときは「○日目」）
- **歯みがき**：今日、わんこ2頭それぞれ済んだか（名前は家族用のスプシの名前表）
- **脳みそ**：新しく作ったカード2枚の題（題が空なら本文の1行目）、種類と番号、全部の枚数
- 右下に「○:○○ 更新」

**小**：タスクの件数・習慣・生理・次の予定だけ

電波がないときなどは、最後に読めた内容を出し、下に小さく「○○：更新できませんでした 時刻」と出ます。読み先ごとに別々なので、どれか1つがだめでも、ほかはいつもどおり出ます（天気が読めないときも、予定・タスクはそのまま）。
ウィジェットを押しても特別なことはしません（Scriptable が開くだけ）。

## 使う合言葉について

ウィジェットには**見るだけ用の合言葉**を貼ります。いつもの合言葉は貼らないでください。
見るだけ用の合言葉で出来るのは、上の内容を見ることだけです（記録を書く・消す、睡眠・コレクション・メモ・予定の場所や中身・ほかのアプリのデータを読む、などはできません）。
家族用のスプシの見るだけ用の合言葉で見られるのは、今日の歯みがきの ○ と、わんこの名前だけです（家族の名前・予定は出ません）。
漏れたかもと思ったら作り直して、スクリプトに貼り替えてください（いつもの合言葉や、ほかの端末のつなぎ直しは不要です）。

天気は無料の気象データ（Open-Meteo）を iPhone から直接読みます。合言葉も登録も要りません。

## 準備（1回だけ）

### 1. スプシのプログラムを新しくする

- **ルーティン（自分用のスプシ）**：`gas/Code.gs` を貼り替えて［デプロイ］→［デプロイを管理］→ 鉛筆 →「新バージョン」→［デプロイ］
- **タスク表**：タスク用の Apps Script（script.google.com で作った専用のプロジェクト）に `task/gas/TaskApi.gs` を貼り替えて、同じように「新バージョン」でデプロイ
- **わんこ（家族用のスプシ）**：家族用のスプシを開き、［拡張機能］→［Apps Script］で同じ `gas/Code.gs` を貼り替えて、同じように「新バージョン」でデプロイ。そのあとスプシに戻り、メニュー「アプリ設定」→「準備をやり直す（setup）」を1回押す（「設定」シートの B6 に見るだけ用の合言葉ができます。入力済みの名前や合言葉は変わりません）

どれも URL は変わりません。自分用のスプシとタスク表では、新しい許可（権限の確認）は出ません。
家族用のスプシで、もし許可の確認が出たら（そのプロジェクトで初めてカレンダーの許可を聞かれる場合）、自分のアカウントで許可してください。プログラムの中に予定合わせ用の部分があるためで、家族用のスプシのウィジェットではカレンダーを読みません。

### 2. 貼る値を6つ用意する

| 貼る場所（スクリプトの上の方） | どこで見るか |
|---|---|
| `routineUrl` | ルーティンのアプリ →「習慣」→ 設定の「ホーム画面のウィジェット」→「送り先URL」の［コピー］ |
| `routineKey` | 同じ画面の「見るだけ用の合言葉」の［コピー］（自分用のスプシの「設定」シートの B6 と同じ） |
| `taskUrl` | タスク用の Apps Script で関数 `taskApiShowViewKey` を実行 → 実行ログの「送り先URL」（［デプロイを管理］のウェブアプリURL、…/exec で終わるもの） |
| `taskKey` | 同じ実行ログの「見るだけ用の合言葉」 |
| `wankoUrl` | 家族用のスプシの「設定」シートの **B2**（接続URL、…/exec で終わるもの）。空なら、家族用のスプシの Apps Script の［デプロイ］→［デプロイを管理］のウェブアプリURL |
| `wankoKey` | 家族用のスプシの「設定」シートの **B6**（見るだけ用の合言葉。B1 のいつもの合言葉ではありません） |

- 使わないものは空のままでかまいません（その欄に「未設定」と出るだけです）
- タスク表の見るだけ用の合言葉を作り直すときは、関数 `taskApiRenewViewKey` を実行します
- ルーティンの見るだけ用の合言葉を作り直すときは、上の画面の「見るだけ用の合言葉を作り直す」を押します
- 家族用のスプシの見るだけ用の合言葉を作り直すときは、B6 を消してから「アプリ設定」→「準備をやり直す（setup）」を押します

### 3. Scriptable にスクリプトを入れる

1. App Store で「Scriptable」（無料）を入れて開く（前の版を入れてあるなら、そのスクリプトを開いて中身を全部入れかえる）
2. 右上の「＋」（新しいスクリプト）を押す
3. `widget/kotowidget.js` の中身を全部コピーして貼る
4. いちばん上の `CONFIG` の `''` の中に、2. の6つを貼る（`'` は消さない）
5. 上の名前を押して「コトのウィジェット」などにする →「Done」
6. 一度そのまま ▶ で実行 → 大の見本が出れば完成

### 4. ホーム画面の1ページに、大と中を置く

1. ホーム画面の空いているページ（なければアプリを1つ長押しして、右へ送って新しいページを作る）の何もないところを長押し → 左上の「＋」（または「編集」→「ウィジェットを追加」）
2. 「Scriptable」を選ぶ → 横にめくって **「大」** を選び「ウィジェットを追加」
3. もう一度 左上の「＋」→「Scriptable」→ **「中」** を選び「ウィジェットを追加」（大の下に置く）
4. 右上の「完了」
5. 大を長押し →「ウィジェットを編集」→「Script」で 3. のスクリプトを選ぶ
6. 中も同じように長押し →「ウィジェットを編集」→「Script」で同じスクリプトを選ぶ
7. 「When Interacting」はそのまま（Open App）でかまいません

小のサイズでも動きます（数字だけ）。

## 困ったとき

- 「未設定」と出る：`CONFIG` のその欄の URL か合言葉が空です
- 「合言葉が違います」：見るだけ用の合言葉を作り直したあとなら、新しい合言葉を貼り直してください
- 「Apps Script が古いようです」「スプシのプログラムを新しくすると出ます」：1. の「新バージョンでデプロイ」がまだです
- 「カレンダーを読めませんでした」：自分用のスプシの Apps Script で関数 `authorizeCalendar` を1回実行して許可し、新バージョンでデプロイしてください
- 「つながりません」：電波を確かめてください。前に読めた内容があればそれを出します
- 「天気を読めません」：天気のサービスにつながらないときです。少し待つと戻ります

## 試験（パソコンで）

```
TZ=Asia/Tokyo node widget/test/widget.test.js
```

Scriptable の部品（Request・ListWidget・SFSymbol など）をまねして、大・中・小それぞれで、読めたとき・夜・読めなかったとき・未設定のとき・どれか1つが落ちているときに、表示が崩れないかを確かめます。
